# Vector Processing Application

### Что представляет из себя приложение

Данное приложение представляет собой консольную программу для работы с 4D векторами и выполнения различных операций над ними. Приложение поддерживает работу с векторами типов `int`, `float` и `double`, обеспечивает:

- **Ввод и хранение векторов** в пулах данных с ограниченным размером (кольцевой буфер)
- **Контроль валидности векторов** - проверка ненулевого состояния w-компоненты (4-го элемента)
- **Сетевые операции** - умножение вектора на матрицу через взаимодействие с удаленным сервером
- **Тестирование подключения** к серверу
- **Тестирование ресурсов** - проверка доступности файлов
- **Работу с сетевыми адресами** в различных форматах (строка, вектор чисел, hex)

**Основные возможности:**
- Интерактивное меню с поддержкой команд
- Валидация векторов по w-компоненте
- Сетевое взаимодействие через JSON
- Логирование ошибок и событий

### Зависимости и окружение

#### Системные требования:
- **Операционная система**: Linux 
- **Компилятор**: GCC 9.0+ или Clang 10.0+ с поддержкой C++17
- **CMake**: версия 3.14

#### Зависимости:

| Зависимость | Версия | Назначение |
|------------|--------|------------|
| nlohmann/json | 3.10.0+ | Работа с JSON для сетевого взаимодействия |
| pthread | - | Потоки (если используются) |

#### Устанавливаемые зависимости:
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install build-essential cmake git
```
Установка nlohmann/json (автоматически через CMake)

#### Инструкция по сборке:
Сборка проекта:
```
mkdir build
cd build
cmake ..
make
```


#### Инструкция по запуску:
Пример:

```
./MyApp -i 127.0.0.1 -p 1100
./MyServer -p 1100
```

# Параметры командной строки 
Клиент:
- IP адрес сервера -i
- Порт сервера -p
- Показать справку --help
- Роль клиента -r    
- Индекс клиента -idx
- Библиотека -L 

Сервер:
- Показать справку --help
- Порт сервера -p

#### Мануал по командам
После запуска приложение предоставляет интерфейс командной строки:

```
=== Меню ===
  name - задать имя программы
  type - выбрать тип вектора (int/float/double)
  vector - ввести вектор (использует выбранный тип)
  connection - тест подключения
  resource - тест ресурсов
  network - ввести сетевой адрес
  matrix - умножить вектор на матрицу (требуется сервер)
  quit/exit - выход

Введите команду:
```

**Подробное описание команд:**
1. name - задать имя программы

```
Введите команду: name
Введите имя программы: app
Имя программы: "app" сохранено
```

2. type - выбрать тип вектора

```
Введите команду: type
Введите тип вектора (int, float, double): int
Тип вектора: int
```

3. vector - ввести вектор (использует тип, который был выбран в type)

```
Введите команду: vector
Введите 4 целых числа через пробел:
1 2 3 4
1 2 3 4 
Вектор int успешно сохранён в пул!
```

Примечение: w-компонента не может быть нулевая

```
Введите команду: vector
Введите 4 целых числа через пробел:
1 2 3 0
1 2 3 0 
Ошибка: 4-й компонент не может быть нулевым!
```


4.connetion - тест подключения

```
Введите команду: connection
ConnectionTest успешен
```

5. resourse - тест ресурсов

```
Введите команду: resource
Введите пути к файлам через Enter (пустая строка для конца):
/home/user/Рабочий стол/Hometask/run.txt


=== Результаты проверки ресурсов ===
  Найден: /home/user/Рабочий стол/Hometask/run.txt

=== Итог ===
Всего файлов: 1
Найдено: 1
Не найдено: 0
Все ресурсы существуют
```

6.network - ввод сетевого адреса

```
Введите команду: network
Выберите способ ввода:
string - через строку (пример: 192.168.1.1:8080)
vector - через вектор (5 чисел: IP4 части и порт)
hex - через hex-значения (IP hex и порт hex)
Ваш выбор: string
Введите адрес в формате IP:ПОРТ (например: 192.168.1.1:8080): 192.168.1.1:8080
Создан сетевой адрес:
IP-адрес: 192.168.1.1 Порт: 8080
```

7. matrix - умножение вектора на матрицу

8. quit/exit - выход

```
Введите команду: quit
Завершение программы
```
